Pilih versi aplikasi untuk Komputer Windows atau Handphone (Android / iOS)

Windows 10 / 11

Versi Desktop Windows (64-bit)

Aplikasi mandiri untuk komputer staf TU. Berjalan cepat dalam mode jendela aplikasi penuh tanpa bilah alamat browser.

  • Paket HTML + Launcher Desktop
  • Mendukung Cetak Langsung ke Printer TU
  • Ukuran Ringan (< 1 MB) & Tanpa Instalasi Rumit
Android & iOS

Versi Mobile Handphone (PWA App)

Akses cepat dari HP Kepala Sekolah maupun Staf TU untuk memantau surat, scan dokumen via kamera HP, dan TTE.

  • Ikon Aplikasi di Layar Utama HP
  • Tanda Tangan Digital Sentuh Layar (Touch)
  • Foto Langsung Surat Masuk dari Kamera HP
Cara Instalasi Cepat ke Layar Utama:
📱 Pengguna Android / iPhone: Buka di Chrome (Android) atau Safari (iPhone), tekan ikon Menu (⋮) / Share lalu pilih "Tambahkan ke Layar Utama" (Add to Home Screen).
💻 Pengguna Windows PC / Laptop: Unduh file Versi Windows (.HTML) atau jalankan Pintasan Desktop (.BAT) untuk membuka aplikasi SIM-SURAT dalam mode jendela desktop.
